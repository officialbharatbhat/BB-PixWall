# BB-PixWall Lite v1.0.0

First stable release of BB-PixWall Lite.

## What is included
- Lightweight automatic wallpaper engine
- Google Photos primary source with Google Drive fallback
- Optional local wallpaper fallback
- Home, Lock, Both Same, and Home/Lock Split modes
- Screen Lock, Screen Unlock, and interval automation
- 32 Hot + 64 Warm local ready-cache targets
- Original-quality wallpaper stream when Blur is disabled
- Per-target Home/Lock blur
- LAN Web Remote with current/next previews and history
- Fast local re-staging of Next wallpapers after apply
- Quick Settings controls
- Standard and optional Advanced/root operation
- Background service and boot recovery

## Lite philosophy
This edition intentionally excludes the heavier AI/context/mood/visual-intelligence systems from the Full edition to prioritize speed, lower runtime overhead, and predictable wallpaper automation.

## Notes
- BB-Remote is LAN-only and requires the controlling device to be on the same local network.
- Android may perform its own final wallpaper handling after BB-PixWall supplies the source stream.
- This GitHub asset is a debug-signed APK build of the Lite v1.0.0 source branch.
